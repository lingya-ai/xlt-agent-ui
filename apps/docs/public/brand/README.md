# 小灵通品牌资源

本目录的 logo.png、logo_white.png、logo_black.png 和 logo-32x32.ico 复制自同一工作区的 xiaolingtong-fe/apps/website/public。
文档站主题依据 xiaolingtong-fe/packages/ui/src/styles/globals.css 的共享明暗主题。亮色阅读界面采用柔和灰绿底色、深色辅助文字和更清晰的输入边框；沿用橙色品牌强调与主按钮。为保留旧 Chromium 支持，站点使用 sRGB 值，通过语义变量统一引用。
资源用于小灵通 / Agent UI 品牌展示，沿用原资源的权利归属。2026-10-21 同步。
